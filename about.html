ABOUT THE PROJECT

A clearer way to explore opportunities.

Northstar Jobs is a responsive front-end portfolio project. It demonstrates semantic HTML, reusable visual patterns, accessible forms, and layouts that adapt from mobile to desktop.

01

Focused discovery

Role cards keep the most useful information visible: discipline, title, purpose, and one direct next step.

02

Accessible by default

Landmarks, descriptive links, visible focus styles, labels, contrast, and reduced-motion support are built into the interface.

03

Honest demo behavior

The contact form validates input in the browser but does not transmit or store personal information.

TECHNICAL SCOPE

Small stack, deliberate execution.

The site uses only HTML, CSS, and JavaScript, so it can be reviewed locally or deployed to any static host without a build step.
